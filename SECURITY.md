# Security policy

There are no releases yet. Only `main` is maintained.

Report a vulnerability privately through [GitHub private vulnerability reporting](https://github.com/kinqsradio/orbyn-planner/security/advisories/new). Do not open a public issue for it.

Include the affected commit, the platform, a minimal reproduction with synthetic data, and what an attacker can do. Never attach real credentials or personal data. No response time is promised.
